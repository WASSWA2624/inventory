# 001 — How to use this plan

**Phase** 01 · Orchestration & working agreements

## Goal

Write the entry document for the plan: one task per file, worked in number order, each producing a shippable, reviewed increment.

## Files

- `dev-plan/README.md` (edit)

## Steps

1. State the rule: a task is finished only when its acceptance boxes are ticked and its tests pass.
2. State that a task may never be widened; anything discovered mid-task becomes a new task file appended to the right phase.
3. Explain the numbering: phase folders are chronological, file numbers are globally unique and never reused.

## Acceptance

- [ ] A developer can read this file alone and know how to start, what "done" means, and where to add new work.
